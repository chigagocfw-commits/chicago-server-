# Item Images Install

Copy every image from:

```text
install/images/
```

into your inventory image folder.

Common locations:

```text
ox_inventory/web/images/
qb-inventory/html/images/
lj-inventory/html/images/
ps-inventory/html/images/
```

The image filenames must stay the same as the item image names in your item definitions.

Examples:

```text
contracts_tablet.png
hack_usb.png
large_drill.png
plasma_cutter.png
WEAPON_DIGISCANNER.png
```

After copying images, restart your inventory resource and clear client cache if icons do not refresh.
