Alternative Map Adaptations

This folder contains alternative contract files that are adapted to work with different map versions or custom interiors. These files are provided purely for convenience, so you don’t have to manually adjust coordinates, doors, or interaction points yourself.

When should you use these?
Use these alternative files if you are running a different version of a supported map, or if your server uses custom interiors that do not match the default configuration shipped with the resource.

How to install an alternative contract:
1. Open this folder and locate the contract file that matches the map/interior you are using.
2. Copy the selected contract file.
3. Go to: lunar_heistcontracts\config\contracts\
4. Find the original contract file with the same name.
5. Replace that file with the copied alternative version.
6. Restart the resource (or your server) to apply the changes.

Important notes:
- These files are optional and only needed if the default interiors do not match your map setup.
- All files are fully open and editable, so you can further tweak positions, doors, or interactions to better suit your server.
- Always keep a backup of the original contract file before replacing it, so you can easily revert if needed.
