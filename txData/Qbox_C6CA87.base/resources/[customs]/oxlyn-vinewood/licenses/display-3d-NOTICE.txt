OXLYN physical display lettering conversion, version 2.6.0

The following native YDR meshes were generated from the same local font outlines
bundled for the NUI. They retain each original typeface's design, including the
supported Latin accents. Font copyright notices and the SIL Open Font License
1.1 are included in googlefonts-OFL.txt in this directory.

Conversion: static font-axis instancing where needed; cap-height normalization;
extrusion with a small high-detail bevel; lower-detail meshes; corrected outward
face winding; native YDR serialization; per-layer color texture UVs. Four color
banks share one source design. Each bank supports natural and emissive shading.
No source font has been replaced by an unrelated font or a planar text image.

Geometry was created by OXLYN using Blender, Sollumz and the CodeWalker validation
toolchain. GTA game map geometry is not part of these font conversions.
